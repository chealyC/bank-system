# Banking System

A simple banking system written in C.

## Features

* Create an account
* Login
* Deposit money
* Withdraw money
* Check balance
* Logout

## Files

```text
main.c    - Main program and menus
bank.c    - Banking functions
bank.h    - Struct and function prototypes
```

## Compile

Using GCC:

```bash
gcc main.c bank.c -o banking_system
```

Then run:

**Windows:**

```powershell
.\banking_system.exe
```

**Linux/macOS:**

```bash
./banking_system
```

## Notes

This is a small practice project for learning C. Account details are only stored while the program is running.
