# Bank System

A simple bank system written in C.

## Features

* Create an account
* Login
* Deposit money
* Withdraw money
* Check balance
* Logout

## Files

```text
main.c    - Main program and menus
bank.c    - Bank functions
bank.h    - Struct and function prototypes
```

## Compile

Using GCC:

```bash
gcc main.c bank.c -o bank_system
```

Then run:

**Windows:**

```powershell
.\bank_system.exe
```

**Linux/macOS:**

```bash
./bank_system
```

## Notes

This is a small practice project for learning C. Account details are only stored while the program is running.
